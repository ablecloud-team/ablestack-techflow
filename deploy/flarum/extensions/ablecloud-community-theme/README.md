# ABLESTACK Community Theme

Flarum Core를 수정하지 않고 ABLESTACK Community의 화면과 한글 사용성을 개선하는 전용 테마 확장입니다.

- ABLESTACK 색상·간격·타이포그래피 적용
- 블루 계열 Hero·배경·카드 경계와 충분한 본문 내부 여백 적용
- 로고보다 작은 타이틀과 압축된 Hero 높이로 콘텐츠 공간 확보
- 240px 카테고리 메뉴와 태그 페이지 버튼 넘침 방지
- 해결 답변의 녹색 카드·상태 칩·선택 미리보기 시각 체계 통일
- 데스크톱 목록의 제목·카테고리·댓글 수 단일 행 배치
- 환영 영역의 위·아래 여백 대칭과 목록 아바타의 제목 중심 정렬
- 상시 표시되는 게시물 답장 아이콘과 사용할 수 없는 버튼의 비활성 상태
- 홈·목록·상세·검색·로그인·글쓰기·첨부 화면 정리
- AI 기술지원, 추가 확인 필요, 최종 해결 가이드의 상태 구분
- FoF Best Answer 사용자 화면 한글화
- FoF Best Answer 검색 상태 문구 한글화
- 모바일 44px 터치 영역, 키보드 포커스, 모션 축소 지원

운영 이상 시 확장만 비활성화하면 Flarum 기본 화면으로 즉시 복귀합니다. Core, Vendor, DB Schema는 수정하지 않습니다.

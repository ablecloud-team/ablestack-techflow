      - paragraph: SCSI 형식은 그대로 유지해도 됩니다. Windows 설치 화면에서 VirtIO SCSI 드라이버(Windows가 SCSI 디스크를 인식하게 하는 소프트웨어)를 먼저 불러오면 설치 디스크가 표시됩니다.
      - paragraph: 먼저 다음 해결 방법을 적용해 보세요.
      - list:
        - text: 디스크 형식은 변경하지 마십시오. Mold의 가상머신 작업 메뉴에서 Windows 설치 ISO를 분리하고,
        - code: VirtIO Windows Driver
        - text: ISO를 연결합니다.
        - text: 가상머신 콘솔의 디스크 선택 화면에서
        - code: Load driver
        - text: 를 누른 뒤
        - code: Browse
        - text: 를 선택합니다. Windows Server 2022라면
        - code: CD Drive\amd64\2k22
        - text: 를 선택하고, 다른 Windows 버전이면 그 버전에 맞는 폴더를 선택합니다.
        - text: 목록에
        - code: VirtIO SCSI controller
        - text: 가 표시되면 선택하고
        - code: Next
        - text: 를 누릅니다. 정상 기준은 드라이버 설치 후 운영체제 설치 위치 화면에 SCSI 디스크가 나타나는 것입니다.
        - text: 디스크가 표시되면 VirtIO 드라이버 ISO를 분리하고 Windows 설치 ISO를 다시 연결합니다. 설치 화면에서
        - code: Refresh
        - text: 를 누른 뒤 설치를 계속합니다.
        - text: 드라이버 목록이 비어 있으면
        - code: 2k22
        - text: 폴더를 그대로 사용하지 말고, 설치 중인 Windows 버전과
        - code: amd64
        - text: 구조에 맞는 폴더를 다시 선택하는 방법을 먼저 시도하십시오. SCSI를 IDE로 바꿀 필요는 없습니다.
        - text: Windows 설치가 끝난 뒤에는 VirtIO ISO의
        - code: virtio-win-gt-x64
        - text: 설치 프로그램으로 나머지 장치 드라이버를 설치하고, 장치 관리자에서 장치 상태가 정상인지 확인할 수 있습니다.
      - paragraph: 이 방법을 먼저 권장하는 이유는 다음과 같습니다.
      - list:
        - listitem: Windows 설치 환경에 VirtIO SCSI 컨트롤러 드라이버가 아직 로드되지 않은 상태입니다.
      - paragraph: 위 조치로 해결되지 않으면 아래 결과를 알려주세요. 이미 제공한 내용은 다시 보내지 않으셔도 됩니다.
      - list:
        - text: 위 절차로 해결되지 않으면 설치 중인 정확한 Windows 버전과
        - code: Load driver
        - text: 에서 선택한 폴더 경로, 드라이버 검색 결과 화면이 필요합니다.
        - code: VirtIO SCSI controller
        - text: 를 설치한 뒤에도 디스크가 없으면 Mold 가상머신 상세 화면에서 해당 디스크가 연결된 상태를 보여주는 화면이 필요합니다.
